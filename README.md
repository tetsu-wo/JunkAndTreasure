## 技術スタック
### フロントエンド (Frontend)
- **フレームワーク:** React 19 / Next.js 15
- **ホスティング (本番OS環境):** Vercel (サーバーレス環境)

### バックエンド (Backend)
- **言語・フレームワーク:** Spring / Java
- **コンテナ/OS (本番環境):** Docker (Debianベース) / AWS ECS (Linux)
- **データベース:** MySQL

### 共通・開発環境 (Development)
- **開発OS:** Windows 11 (PowerShell)
- **ローカル環境:** Docker / Docker Compose （環境の差異をなくすため共通化）
